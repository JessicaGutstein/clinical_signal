# Third-party files in this folder

| File | What it is | Source and licence |
|---|---|---|
| `vendor/d3.min.js` | D3 7, used for the map and the chart | https://d3js.org, ISC licence |
| `fonts/atkinson-hyperlegible-next-latin-wght-normal.woff2` | Atkinson Hyperlegible Next typeface | Braille Institute, via Fontsource, SIL Open Font Licence 1.1 |
| `geo/region.geojson` | Simplified land and borough outlines | Borough outlines from NYC Open Data (via Code for Germany's click_that_hood); surrounding land from US Census ZIP code tabulation areas (via OpenDataDE). Simplified with mapshaper. |

These are bundled so the prototype runs without an internet connection.
